# Shared policy: AMP benchmark task scope

- The primary task is binary antimicrobial-peptide identification/classification from peptide sequences.
- Keep AMP classifiers and predictors as candidates even when reproducibility evidence is incomplete; record their blocking issues instead of inventing readiness.
- Do not place ACP, AIP, AVP, AFP, CPP, toxicity-only, MIC-regression, generative/design or database-scanning systems in the primary deployment ranking.
- A repository, web server, training framework or benchmark suite is not automatically an executable pretrained model.
- Merge aliases and version spellings into one canonical model record while preserving the aliases and provenance.
