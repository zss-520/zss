# Shared policy: auditable meeting output

- Return one valid JSON value without Markdown fences or prose outside JSON.
- Use the runtime-supplied schema and exact keys. The code validates types, required fields, enums and numeric constraints.
- Keep proposal, criticism, rebuttal, dissent, uncertainty and final decision distinguishable.
- Do not rewrite computed benchmark values, gate outcomes, file paths or rankings.
- If the supplied evidence cannot support a required decision, record the gap instead of fabricating a complete answer.
