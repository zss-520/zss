# Shared policy: repository evidence

- README Download, Installation, Usage, Predict, Inference and Test instructions are the primary evidence for commands and assets.
- Use requirements files, environment files and imports as supporting evidence; do not assume that every stale dependency is required by the active inference path.
- Do not invent a command, weight URL or output file. Mark uncertain command reconstruction for manual verification.
- Return semantic recommendations only. Path containment, command safety, dependency normalization and output validation are enforced by code.
