**Supplementary Figs. S1–S7 | Stage-resolved, file-backed multi-Agent workflow for AMP benchmarking.** **S1,** Entry, configuration and run provenance. The unified menu, configuration loader, workflow guards and run manifest establish the authorized execution context. **S2,** Literature search, recommendation and persistent memory. Evidence Compressor, Information Extractor, Model/Dataset Scout, Metrics, Critic and Chief agents transform retrieved literature into screened evidence, persistent memory and frozen recommendation tables. **S3,** Repository registration and HPC deployment. README-derived contracts are converted into registry records, isolated environments and bounded self-healing evidence before smoke-test admission. **S4,** Dataset benchmarking. Automatic HPC predictions and manually imported prediction tables remain separate until both satisfy the common sample, label and probability schema and enter the same scientific evaluator. **S5,** Fifty-round multi-Agent ranking. Blinded Literature, Statistics and Screening proposals undergo independent Reviewer audit and Chief reconciliation before all accepted weight vectors and model scores are persisted. **S6,** Top-3 and ensemble analysis. All three-model combinations are evaluated without model-specific bonuses, and the recommended trio is retained as exploratory pending untouched external validation. **S7,** Figures and quality assurance. Publication assets, source data and QA records expose stored evidence but never feed values back into scoring. Green labels identify verified handoffs, and orange arrows or rules identify ordered execution and non-negotiable constraints. Source data are provided with the figures.
