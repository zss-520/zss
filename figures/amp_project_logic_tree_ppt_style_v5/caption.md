**Supplementary Fig. X | Repository logic tree and auditable evidence handoffs of the AMP benchmark.** The seven ordered repository stages are shown in an A4 portrait supplementary-methods format. Each branch links versioned Agent Markdown contracts to explicit entry or Python execution files and then to durable intermediate or terminal artifacts. Stage 0 establishes configuration, workflow guards and run provenance. Stage 1 converts literature evidence into a compact pool, screening decisions, persistent memory and frozen model, dataset and metric recommendations. Stage 2 converts model repositories into registered HPC environments with smoke-test and bounded self-healing records. Stage 3 retains separate automatic HPC and manual prediction-import branches until both enter the common scientific evaluation protocol. Stage 4 retains the blinded Literature, Statistics and Screening proposals, independent Reviewer audit, Chief decision and 50 round-specific JSON records before the terminal ranking is written. Stage 5 converts the stored ranking into Top-3 and ensemble-learning evidence, whereas Stage 6 contains presentation and quality-assurance outputs that never feed values back into scoring. The summary band reports 2,365 literature records, 20 recommended models, three test datasets and 50 decision rounds. Green labels identify persisted handoffs verified in the current project state; orange arrows indicate file-to-file execution handoffs. Source data are provided with the figure.
