# Figure contract

- Core conclusion: the AMP benchmark is controlled by auditable role-specific prompts, deterministic gates and persisted intermediate evidence rather than one opaque LLM call.
- Evidence chain: each prompt record names its system role, runtime task, verified project output and source file.
- Archetype: text-led supplementary methods atlas, one A4 portrait page per project stage.
- Backend: Python/matplotlib only.
- Adaptation level: style-only inheritance from the user-provided prompt appendix page; all scientific content comes from this project.
- Export: editable SVG and PDF, 300 dpi PNG preview, combined five-page PDF and source CSV.
- Integrity: runtime payloads are abbreviated for page fit; no metric, model, dataset or output count is invented.
